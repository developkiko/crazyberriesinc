# Crazy Berries Inc. — описание проекта (as-is)

## Что это

Витринно-каталожный сайт компании **Crazy Berries Inc.** (Статен-Айленд, Нью-Йорк) — импортёр и
оптово-розничный продавец сушёных ягод, сухофруктов, ягодных соков и фруктов в тёмном шоколаде
из Европы. Сайт-визитка с каталогом «без цен и без оплаты»: покупки и опт оформляются через
телефон/e-mail/форму обратной связи.

- Прод: https://crazyberries.vercel.app/ (статика на Vercel)
- Репозиторий: https://github.com/developkiko/crazyberriesinc
- Локальная копия: `old/crazyberriesinc-main/` (распакован из `crazyberriesinc-main.zip`)

## Происхождение и текущий тулчейн

Сайт — это **статический дамп (зеркало) живого сайта на Drupal 7**, снятый HTTrack
28.06.2023 с хостинга `f0832486.xsph.ru` и выложенный на Vercel как есть (чистая статика,
без сборки). Следовательно:

| Слой | Что используется |
|---|---|
| Генератор | нет — готовые `.html` файлы, отдаются Vercel как static |
| Оригинальная CMS | Drupal 7 (тема `us` на базе Zen, SASS) |
| JS | jQuery **1.5.2** (2011), jquery.once, FlexSlider (слайдер на главной), Colorbox (лайтбокс), Drupal JS-ядро |
| CSS | ~10 агрегированных CSS-файлов Drupal (в т.ч. `sites/all/themes/us/css/styles7d44.css`, 49 КБ), grid на Bootstrap-классах (`col-xs-12 col-lg-3`) |
| Аналитика | Google Analytics **UA-92095914-1** — счётчик UA закрыт Google в июле 2023, данные не собираются |
| Сборка/деплой | нет; push в GitHub → Vercel отдаёт файлы |
| Тесты/линтеры/TS | отсутствуют |

## Структура и объём контента

```
index.html                     главная (слайдер FlexSlider + текст о компании + сетка категорий)
catalog.html                   список категорий (4)
catalog/*.html        (21)     страницы категорий/подкатегорий
content/*.html        (40)     карточки товаров (≈36) + about-us, contact-us, crazy-berries
taxonomy/term/*.html  (21)     дубли-термины Drupal (SEO-мусор)
node/*.html           (39)     дубли-ноды Drupal (SEO-мусор, часть битых ссылок)
misc/, modules/, sites/        ядро/модули Drupal, библиотеки, тема
sites/default/files/  (9.2 МБ) все изображения товаров
.idea/                        мусор IDE в репозитории
```

Категории (4):

1. **BERRY JUICES** — соки: aronia 200/720 ml, blackberry 200 ml, blueberry 200 ml, blackberry-blueberry mix 200 ml
2. **DRIED BERRIES** — aronia, blackberry, black currant, wild blueberry, lingonberry, raspberry, seaberry (облепиха), strawberry, wild strawberry, tart cherry и др.
3. **DRIED FRUITS** — персики, груши, сливы (3.5 oz / 100 г)
4. **DARK CHOCOLATE-COVERED FRUITS** — абрикос, арония, ежевика, чёрная смородина, черника, нут, клюква, персик, груша, слива, малина, клубника, семечки, вишня в шоколаде

Карточка товара: фото, название, категория, описание (польза/вкус), **Ingredients**, **Storage**, контактный блок. Цены и кнопки покупки **отсутствуют**.

## Ассеты

- Все изображения лежат в `sites/default/files/` (+ производные `styles/category|medium/public/`), 9.2 МБ суммарно.
- Форматы: JPG/PNG, без WebP/AVIF, без lazy-loading, без сжатия; имена файлов — смесь транслита, кириллицы (`малина_шок.jpg`) и мусорных суффиксов Drupal (`unnamed (3)_0fff8.jpg`) — URL-закодированные кириллические пути.
- Логотип: `sites/default/files/logo_0.png` (+ копия в `imgs/logo_0.png` вне дампа).
- Сырые кандидаты на фон для нового сайта лежат в `imgs/to-upscale/` (5 шт., требуют апскейла/подготовки).

## Состояние (диагностика проблем)

**SEO — практически нулевое:**
- нет `meta description` ни на одной странице, нет OG/Twitter-карточек;
- заголовки шаблонные («X | Crazy Berries», главная — «Crazy Berries | Crazy Berries»);
- индексируемые дубли: `node/*`, `taxonomy/term/*`, `content/*` — три URL на один товар (каннибализация);
- нет `sitemap.xml`, `robots.txt`, `404.html`; нет структурированных данных (только RDFa-мусор Drupal);
- кириллические/нечитаемые URL картинок.

**UX/функциональность:**
- нет корзины, цен, заказа; форма контактов (webform) на статике мертва;
- нет мобильного меню (меню просто складывается колонкой), адаптив — минимальный (Bootstrap-классы 2015 г.);
- нет тёмной темы, нет PWA, нет офлайна;
- часть внутренних ссылок битая (в дампе — на `node/11`, `content/peach-chocolate` без `.html`).

**Производительность:**
- jQuery 1.5 + FlexSlider + Colorbox + ядро Drupal ≈ тяжёлый JS для простого каталога;
- CSS через `@import` (блокирующие цепочки);
- картинки без оптимизации; общий вес сайта ~12 МБ.

**Вывод:** контент и структура каталога переносимы 1-к-1 (тексты, состав, хранение, фото);
техническая часть не подлежит апгрейду — только полная пересборка (см. `upgrade.md`).
